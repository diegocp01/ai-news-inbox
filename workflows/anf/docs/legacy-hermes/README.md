# Retained original ANF instructions

These are complete sanitized copies of the user-supplied legacy files, not current runtime tool instructions. Read [the migration guide](../INTAKE-MIGRATION.md) for precedence, cloud adaptation, known inconsistencies, and cutover gates. The original MIT license declarations are retained.

The personal name was generalized to “the user.” No lines or references were shortened or omitted. Absolute machine paths, runtime secrets, private Telegram identifiers, queue/history contents, and private reconciliation IDs are not in this folder. Generic historical `~/.hermes` paths remain as documentation of the old commands; use the cloud runner’s configured storage and delivery adapter instead.
